# Classic Status Bar for Firefox

A  userChrome.js script that restores the classic status bar in new versions of firefox!

## Features

- The status bar
- URL hover
- Page loading progress bar (hidden when page loaded)
- HTTPS indicator
  - Displays a lock icon on webpages with HTTPS
  - Shows certificate issuer information on hover

## Installation

1. Copy the contents of the Firefox folder into the Firefox directory (e.g. C:/Program Files/Mozilla/Firefox)
2. Copy the contents of the profile folder into your user profile
3. Restart Firefox!

Note: You may have to clear startup cache in about:support before it works!

## Compatibility

Tested on:

- Firefox 128 ESR
- Firefox 140+
